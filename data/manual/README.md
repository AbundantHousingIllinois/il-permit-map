# Hand-maintained data

Nothing in this directory is generated by a script. The build reads these files as-is.

## `ahpaa.csv`

Affordable Housing Planning and Appeals Act (AHPAA) non-exempt status by municipality.

**This file ships with headers and zero data rows on purpose.** The AHPAA
non-exempt list is a periodic determination published by the Illinois Housing
Development Authority (IHDA). There is no API and no machine-readable feed for
it, so it cannot be fetched at build time, and it must never be generated from
a language model's recollection — a wrong compliance status attached to a named
municipality in legislative testimony is a serious error.

Steffany populates this file from the current IHDA determination list.

### Columns

| Column | Meaning |
|---|---|
| `geoid` | 7-character Census place GEOID (`17` + 5-digit FIPS place code), e.g. `1782075` for Wilmette. Must match a GEOID in `docs/data/places.geojson`. |
| `municipality` | Municipality name as published by IHDA. Kept for human verification; the join uses `geoid`. |
| `status` | IHDA determination, verbatim. e.g. `non-exempt` or `exempt`. |
| `source_url` | URL of the IHDA document the row was read from. |
| `as_of_date` | Date of the IHDA determination (`YYYY-MM-DD`), not the date the row was typed. |
| `notes` | Anything a reader needs in order to trust the row. |

### Where the list comes from

IHDA publishes AHPAA determinations under its Affordable Housing Planning and
Appeals Act program pages (ihda.org). The determination is periodic, so the
`as_of_date` matters and belongs on the site.

### What the build does with it

- **Zero rows** → `ahpaa_status` is `null` for every place, and the site disables
  the AHPAA filter with a tooltip explaining that the list has not been loaded.
  This is a normal, passing state.
- **Rows present** → each `geoid` gets its `status`; places absent from the file
  stay `null` (unknown), which is never rendered as "exempt".

A `geoid` in this file that does not exist in the built data is reported by
`scripts/check_data.py` rather than silently dropped.
